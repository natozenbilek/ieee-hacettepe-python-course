1. Python 3.14

Python 3.15, 9 Ekim 2026'da çıktı. Araçların yeni sürüme uyması zaman aldığı için derste 3.14 kullanacağız. Bilgisayarınızda 3.13 ya da 3.15 kuruluysa onunla da devam edebilirsiniz.

Windows

  1. Python 3.14.8 sürüm sayfasını açın.
  2. Sayfanın sonundaki Files tablosunda Windows installer (64-bit) bağlantısına tıklayın. Sayfanın üstündeki Download Python install manager düğmesi başka bir araç indirir, onu kullanmayacağız.
  3. İşlemciniz Snapdragon ise bunun yerine Windows installer (ARM64) satırını seçin. İşlemcinin adı Ayarlar › Sistem › Hakkında ekranında yazar.
  4. İnen python-3.14.8-amd64.exe ya da python-3.14.8-arm64.exe dosyasını çalıştırın.
  5. İlk ekranın altındaki Add python.exe to PATH kutusunu işaretleyin. Bu kutu işaretliyse python komutu Komut İstemi'nde de çalışır.
  6. Install Now'a tıklayın. Setup was successful yazısı çıkınca Close ile kapatın.
  7. Başlat menüsünde cmd yazıp Komut İstemi'ni açın, python --version yazıp Enter'a basın. Python 3.14.8 yazmalı.

macOS

  1. Python 3.14.8 sürüm sayfasını açın.
  2. Download macOS installer bağlantısına tıklayın. Aynı dosya sayfanın sonundaki Files tablosunda da var.
  3. İnen python-3.14.8-macos11.pkg dosyasını açıp kurulum penceresindeki adımları geçin. Mac'iniz parolanızı sorabilir.
  4. Cmd + Space ile Spotlight'ı açın, Terminal yazıp Terminal'i açın.
  5. python3 --version yazıp Enter'a basın. Python 3.14.8 yazmalı.

Komutun adı Windows'ta python, macOS'ta python3. Derste kodu PyCharm'da çalıştıracağız, bu komutu yalnızca kurulumu kontrol etmek için kullandık.

2. PyCharm ve öğrenci lisansı

Windows

  1. PyCharm indirme sayfasından Windows için .exe dosyasını indirin. Snapdragon işlemcili bilgisayarlarda ARM64 sürümünü seçin.
  2. Dosyayı çalıştırıp kurulum sihirbazını Next ile geçin. Seçenek kutularını işaretlemeniz gerekmiyor.
  3. Kurulum bitince PyCharm'ı Başlat menüsünden açın.

macOS

  1. PyCharm indirme sayfasından macOS için .dmg dosyasını indirin. Apple Silicon ve Intel için ayrı dosyalar var. Apple menüsü › Bu Mac Hakkında ekranında Çip satırı varsa Apple Silicon, İşlemci satırında Intel yazıyorsa Intel sürümünü seçin.
  2. .dmg dosyasını açıp PyCharm'ı Uygulamalar klasörüne sürükleyin.
  3. PyCharm'ı Uygulamalar klasöründen ya da Spotlight'tan açın.

PyCharm ilk açılışta Pro sürümün denemesini başlatıyor, derste kullanacağımız her şey deneme bitince de ücretsiz çalışıyor.

Öğrenci lisansı

JetBrains, Hacettepe e-posta adresiyle başvuran öğrencilere ücretsiz lisans veriyor, bu lisansla Pro özellikler de açık kalıyor.

  1. JetBrains'in öğrenci lisansı başvuru formunu açın.
  2. Formu @hacettepe.edu.tr uzantılı e-posta adresinizle doldurup gönderin.
  3. Bu adrese gelen JetBrains e-postasındaki bağlantıyı açın. Lisans koşullarını okuyup kabul edin, sonra bir JetBrains hesabı açın ya da hesabınız varsa ona girin.
  4. PyCharm'da Help › Manage Subscriptions penceresini açın. Windows'ta bu menü sol üstteki ana menü düğmesinin altında.
  5. Pencerenin sol altındaki Log in düğmesiyle aynı hesaba girin ve listede görünen öğrenci lisansını Activate ile etkinleştirin.

Onay gelene kadar sonraki adımlara geçebilirsiniz.

3. python-kurs projesi

Derslerde yazacağımız bütün dosyalar python-kurs adlı tek bir PyCharm projesinde duracak.

PyCharm kodu çalıştırmak için bilgisayardaki bir Python'u kullanır, buna interpreter (yorumlayıcı) diyoruz. Hangi Python'u kullanacağını projeyi açarken seçeceksiniz.

Yolunda Türkçe karakter ya da boşluk olan klasörler ve OneDrive'ın eşitlediği klasörler bazı araçlarda sorun çıkarıyor. Bu yüzden proje için şu klasörü kullanın:

Windows

C:\python-kurs

Masaüstü ve Belgeler çoğu bilgisayarda OneDrive'a bağlı, Windows kullanıcı adınızda da Türkçe karakter olabilir. Bu yüzden projeyi doğrudan C:\ altında açıyoruz.

macOS

/Users/mehmet/python-kurs

mehmet yerine kendi kullanıcı adınızı yazın, Location alanında /Users/'tan sonra gelen kısım odur. Masaüstü ve Belgeler iCloud'a bağlı olabildiği için klasörü doğrudan ev klasörünüzde açıyoruz.

  1. PyCharm'ın karşılama ekranında New... düğmesine tıklayıp açılan listeden New Project'i seçin (Şekil 1). Açık bir proje varsa File › New Project menüsünü kullanın.
  1. Soldaki listede Pure Python seçili olsun.
  2. Location alanındaki yolu silip yukarıdaki yolu yazın. Proje adı yolun son kısmından, python-kurs olarak gelir.
  3. Create a welcome script kutusunun işaretini kaldırın.
  4. Interpreter type olarak Project venv seçili kalsın. PyCharm proje klasöründe .venv adında bir klasör açar ve proje Python'u bu klasörden kullanır.
  5. Python version listesinden 3.14'ü seçin (Şekil 2).

Listede 3.14'ün yanında download and install yazıyorsa 3.14 bilgisayarınızda kurulu değil demektir. O satırı seçerseniz PyCharm Python'u python.org'dan indirip kurar (Şekil 3).

macOS'ta listede /usr/bin/python3 yolundaki Python 3.9 da görünebilir, onu seçmeyin. macOS'un geliştirici araçlarıyla gelen bu eski sürümü kurulum testi kabul etmiyor.

  1. Create'e tıklayın. PyCharm ilk açılışta dosyaları tarıyor, alttaki ilerleme çubuğu bitene kadar bekleyin.

Soldaki Project penceresinde python-kurs klasörünü, sağ alttaki durum çubuğunda da Python 3.14'ü görmelisiniz.

4. Inline completion'ı kapatma

PyCharm siz yazarken bir dil modeliyle satırın devamını gri yazıyla öneriyor. Derste kodu kendimiz yazacağız, o yüzden bu öneriyi kapatın.

  1. Windows'ta Ctrl + Alt + S, macOS'ta Cmd + , ile Settings penceresini açın.
  2. Soldaki listede Editor › General › Code Completion › Inline sayfasına gidin.
  3. Enable inline completion using language models kutusunun işaretini kaldırıp OK'e tıklayın (Şekil 4).

5. Kurulum testi

  1. Soldaki Project penceresinde python-kurs klasörüne sağ tıklayıp New › Python File'ı seçin (Şekil 5).
  1. Ad olarak kurulum_testi yazıp Enter'a basın. PyCharm dosyayı kurulum_testi.py olarak açar.
  2. Aşağıdaki kodu kopyalayıp bu dosyaya yapıştırın. Dosyayı kurulum_testi.py bağlantısından da indirebilirsiniz.
  1. Pencerenin üstündeki çalıştırma listesinde Current File seçili olsun, yanındaki yeşil Run düğmesine tıklayın. Windows'ta Ctrl + Shift + F10, macOS'ta Ctrl + Shift + R kısayolu da aynı işi yapar.
  1. Altta Run penceresi açılır ve program adınızı sorar. Run penceresinin içine tıklayıp adınızı yazın ve Enter'a basın.

İlk satırda projenin Python sürümü, son iki satırda da adınız görünmeli. Program Bu sürüm eski yazıyorsa proje eski bir Python'la açılmış demektir, Sık karşılaşılan sorunlar bölümündeki ilk maddeye bakın.

Sık karşılaşılan sorunlar

No Python interpreter configured uyarısı ya da Bu sürüm eski çıktısı

  1. Settings penceresini açıp Python › Interpreter sayfasına gidin (Şekil 6).
  2. Listede 3.14 ile kurulmuş bir ortam varsa onu seçip OK'e tıklayın.
  3. Yoksa Add Interpreter › Add Local Interpreter'ı seçin, Virtualenv türünde Base Python olarak 3.14'ü seçip OK'e tıklayın.

3.14, Python version listesinde hiç görünmüyor

  1. PyCharm'ı kapatın, 1. adımdaki kurulumu yapın ve PyCharm'ı yeniden açın.
  2. Hala görünmüyorsa Interpreter type olarak Custom environment'ı seçin ve Base Python listesinin yanındaki düğmeyle şu dosyayı gösterin:

Windows

C:\Users\mehmet\AppData\Local\Programs\Python\Python314\python.exe

Buradaki mehmet sizin Windows kullanıcı adınız.

macOS

/Library/Frameworks/Python.framework/Versions/3.14/bin/python3

Run başka bir dosyayı çalıştırıyor

  1. Pencerenin üstündeki çalıştırma listesini açıp Current File'ı seçin. Run o zaman editörde açık olan dosyayı çalıştırır.

Run'a basınca program duruyor, sonuç gelmiyor

  1. Program büyük ihtimalle adınızı bekliyor. Alttaki Run penceresinin içine tıklayıp adınızı yazın ve Enter'a basın.

Yazdığınız ad kodun içine girdi

  1. Adı editöre yazmışsınız. Windows'ta Ctrl + Z, macOS'ta Cmd + Z ile geri alın.
  2. Programı yeniden çalıştırın, adı yazmadan önce Run penceresinin içine tıklayın.

SyntaxError: invalid character '“' (U+201C)

  1. Kodu WhatsApp'tan ya da bir belgeden kopyaladığınızda düz tırnak " eğik tırnağa “ ” dönüşebilir. Python eğik tırnağı tanımaz.
  2. Error message'ın gösterdiği satırda tırnakları silip klavyeden yeniden yazın.

NameError: name 'prınt' is not defined. Did you mean: 'print'?

  1. Türkçe klavyede i yerine noktasız ı yazılmış. Error message'ın son satırı hatanın adını ve açıklamasını verir.
  2. Mesajda line 1 ile gösterilen satırda prınt yerine print yazın.

Şekil 7'de başka bir NameError var, bu kez PyCharm'ın Run penceresinde. Satır nmae adını kullanıyor ama programda böyle bir isim yok, ^^^^ işaretleri de bu adın altında duruyor. PyCharm error message'ı kırmızıyla gösteriyor.

Windows'ta python yazınca Microsoft Store açılıyor ya da Python was not found yazıyor

  1. Kurulumda Add python.exe to PATH kutusu işaretlenmemiş. PyCharm Python'u kendisi bulduğu için derste bu bir sorun çıkarmaz.
  2. Kurulumu Komut İstemi'nde py --version yazarak yine de kontrol edebilirsiniz.
  3. python komutunu da açmak isterseniz kurulum dosyasını yeniden çalıştırıp Modify'ı seçin. Optional Features sayfasını Next ile geçin, Advanced Options sayfasında Add Python to environment variables kutusunu işaretleyip Install'a tıklayın. Sonra yeni bir Komut İstemi penceresi açın.

macOS'ta python3 --version 3.9 yazıyor ya da geliştirici araçlarını kurmak isteyen bir pencere açılıyor

  1. Python 3.14 henüz kurulmamış ya da Terminal penceresi kurulumdan önce açılmış. Açılan pencereyi kapatın, gerekirse 1. adımdaki kurulumu yapın.
  2. Yeni bir Terminal penceresi açıp python3 --version komutunu yeniden yazın.

Proje klasörünün yolunda Türkçe karakter var ya da klasör OneDrive'da

  1. File › New Project ile projeyi 3. adımdaki yolda yeniden oluşturun.
  2. kurulum_testi.py dosyasını yeni klasöre taşıyın.

Program bitmiyor

  1. Run penceresindeki kırmızı kare Stop düğmesine tıklayın. Windows'ta Ctrl + F2, macOS'ta Cmd + F2 kısayolu da programı durdurur.

Burada olmayan bir sorunla karşılaşırsanız ekran görüntüsüyle birlikte dersin WhatsApp grubuna yazın.
